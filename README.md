## 怎么读

- **不用全做**：这是一份按性价比排好的备选单，不是任务清单。挑走一两条就算数，剩下的放着，需要时再回来查。「说着容易做着难」这个评价是对的，写下来是为了要用的时候找得到。想挑省力的，看下面「只想看最值得做的」那条。
- **想让 AI 帮你查**：仓库里带了一个中文 skill（[skills/workplace-decision-guide](skills/workplace-decision-guide/)），Claude Code 和 Codex 都能装。装上以后直接问「加班费按几倍算」「朋友让我替他的公司签担保，签不签」。它会先把相关条目从正文里查出来，再照书里的算账方式排序回答，并注明出自第几节第几条。查不到就说查不到，不自己编数字。装法见 [那个目录的说明](skills/workplace-decision-guide/README.md)。
- **想按条件挑**：打开[在线检索页](https://tomcatmartion.github.io/Workplace-Survival-Handbook/)，可以按关键词、章节、证据等级来筛，也可以按「花不花钱、花多少时间、要不要毅力」这三样筛，几个条件能叠着用。页面上的内容直接取自 book/ 目录里的正文，正文一改，页面跟着改。
- **条目之间会互相指路**（「见第 15 节第 3 条」这种）：在检索页里，这种指路带一条虚线。点一下，就地显示被指的那条的标题和「说人话」。想真的翻过去，再按「跳过去」。那一条正好被筛选条件藏起来了，页面会自动把筛选清掉。在 GitHub 上直接读正文点不动，但每处指路后面都写着指向什么（「见第 15 节第 3 条（开张前选对主体）」）。不翻过去也知道说的是哪条。
- **想按顺序读**：每节内的条目按性价比从高到低排列，从每节前几条开始看就行。
- **想离线看、想发给别人**：下载离线单文件 HTML，整篇连同检索和筛选都在这一个文件里，双击就开，不用服务器也不用联网。自己生成的办法见下面「自己跑一份」。
- **看不懂那串数字**：每条都有一行「说人话」。它把「收益」栏里那些法条和数字，翻成「能给多少钱、会摊上什么后果」这样的日常说法。它只用「收益」栏已经写到的内容，不添新数字。只看这一行就够拿主意。「收益」栏里原样留着条款号和原文，想自己核对就看那一栏。
- **只想看结论最硬的**：在检索页里勾选证据等级 A，只留下引到了法条或官方文件原文的 881 条。
- **只想看最值得做的**：勾选性价比「极高」，得到既不花钱、不花时间、不需要毅力，收益又落在最大一档的条目。再叠加一个「换回什么」，就是该口径下的优先清单。
- **看到「别」「不要」开头的节标题不用紧张**：节标题说的是这一节想防住的事（别把身体搭进去、别把自己送进去），不是说底下每条都在让你别干什么。真正要做的动作写在条目标题里，一律动词开头，自己就写清了是「做什么」还是「别做什么」。按条目标题读，不用往节标题的语气上套。
- **看到「框架阶段」的提示**：那一节的条目清单已经定好，正文还没逐条写出。清单里每一条都写清了计划条号和主题，按 CLAUDE.md 的条目格式补齐即可，条号不要挪动——别处已经有引用指到这些条号上。

每条建议长这样：

```markdown
### 1. 加班费按 1.5 倍、2 倍、3 倍三档算，公司不给就去投诉劳动监察

- 成本：不花钱。每月把打卡记录、排班表和加班审批单存一份，工作群里派活的消息也截图留着。难在每个月都要记得存。
- 说人话：平时加班按工资的 1.5 倍给钱。休息日加班又没安排补休的，按 2 倍。法定节假日上班按 3 倍，而且不能拿补休顶掉。公司不给，就去劳动监察投诉。被责令限期付清还不付的，要另外加付欠款的一半到一倍。
- 收益：法律规定每天上班不超过 8 小时，平均每周不超过 44 小时。安排延长工作时间的，支付不低于工资的 150% 的工资报酬。休息日安排工作又不能安排补休的，支付不低于工资的 200% 的工资报酬。法定休假日安排工作的，支付不低于工资的 300% 的工资报酬。用人单位安排加班不支付加班费的，由劳动行政部门责令限期支付；逾期不支付的，责令用人单位按应付金额 50% 以上 100% 以下的标准向劳动者加付赔偿金（全国）
- 证据等级：A
- 来源：全国人大常委会 (2018). 劳动法（2018 年第二次修正，第三十六、四十一、四十四、九十一条）. <https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/bgt/art/2023/art_d9aa750028b14b99a776cb93726a360d.html>（国家市场监督管理总局刊登）；全国人大常委会 (2007). 劳动合同法（第八十五条第三项）. <http://www.gov.cn/gongbao/content/2007/content_711013.htm>
- 备注：法定节假日全年只有元旦、春节、劳动节、国庆节这类法定的那几天。调休凑出来的连休日按休息日算，给 200%。「公司规定加班要审批」「我是自愿留下的」这两句话不等于公司就可以不给钱，但会让你更难拿出证据，所以派活和审批记录要留着。投诉和仲裁都不收费，走法见第 9 节第 1 条（先投诉劳动监察）。
```

```bash
git clone https://github.com/tomcatmartion/Workplace-Survival-Handbook.git
cd Workplace-Survival-Handbook
python -m http.server 8000
```

然后浏览器开 `http://localhost:8000/`。检索页是纯静态的，`README.md` 和 `book/` 就是它的数据，没有后端、没有数据库、不用装依赖；把整个目录丢给任何静态服务器（Nginx、GitHub Pages、对象存储）效果一样。注意 `index.html` 必须经 http 打开，直接双击本地文件会空白——浏览器不许网页读本地文件，那种场景请生成离线单文件版：

```bash
node tools/offline/build.mjs     # 离线单文件 HTML，产物在 dist/，双击就开
```

## 四种资源

这本书想帮你多留住的不只是工资，一共四样东西：

- **收入与积累**：该拿到的钱拿到手，不该亏的不亏，把钱花在收益确定的地方
- **时间与精力**：活着的时间不花在没有回报的事上，每天的注意力和体力少被白白耗掉
- **健康余量**：别把未来几十年的身体，换成这几年多出来的那点钱
- **人身自由**：不因为不知道一条红线，把自己送进拘留所或者看守所

每一条建议都回答两个问题：要花掉什么（钱/时间/精力/毅力），能换回什么（收入与积累 / 时间与精力 / 健康余量 / 保障与人身自由）。条目按性价比排，不按类别排：几乎不花什么成本、换回的好处又大的，放在最前面。

**一条建议的好处落在谁身上，是分档的。** 按「这份好处将来有多大可能回到你自己身上」从高到低：① **你自己**；② **配偶和直系亲属**（父母、子女、祖父母外祖父母、孙子女外孙子女）；③ **朋友、同事和其他亲属**——互惠关系，帮出去的将来可能回来；④ **陌生人**——最低一档，但不是零：回报的概率小，而且你不了解对方性格，还有被讹、被反咬、被报复的一面。不同档不合并计算，写到第 ④ 档时好处和风险一起写。

职场这一侧照这个读：替人担保、帮人签字、代持股权这类事，好处全在别人身上，风险全在你名下，写的时候两边都要摆出来，不替你把它算成非做不可的理由。

四类数字各算各的，不互相折算。「每月多拿 800 元」和「连续两年睡不好」不在一把尺子上。

## 证据分级

每条建议都标注证据等级：

| 等级 | 含义                                       |
| -- | ---------------------------------------- |
| A  | 有具体条款或官方文件可查，能说出金额、期限、比例，来源栏的链接能打开核对     |
| B  | 有法规或官方文件支撑，但说不出一个确切数字；或者只有部门规范性文件、地方口径撑着 |
| C  | 作者自己的经验，或者大家公认的做法，没有直接的文件依据              |

全书 1108 条中 A 级 881 条、B 级 155 条、C 级 72 条，另有 3 处标注了待核实。有争议的 A/B 级条目会标注「争议」并列出反方证据。所有来源只引原始文件（法律、行政法规附国务院公报或人大网链接，部门规章附部委官网或 gov.cn 转载页），不引二手转述。找不到官方原文的数字标「待核实」，不当结论用。

A 级只说明「有明文、出处可核」，不说明「你一定拿得到」。写到「法律支持你」的条目，必须连过程成本一起说：要不要打官司、大概多久、律师费谁掏。只说结果不说过程，等于把胜诉率当成收益。

## 性价比档

证据等级只回答「这个说法可不可信」，不回答「这件事值不值得做」。所以每条还另外标了两样：收益量级（好处有多大）和口径（换回的是哪一类东西）。检索页拿这两样加上三项成本，合出一个性价比档：

| 维度   | 取值                       | 怎么定的                                                                                                                                                                    |
| ---- | ------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 口径   | 换钱 / 换时间精力 / 换健康 / 换人身自由 | 看这条主要换回的是什么。**不同口径之间不做比较**，「一个月多拿 800 元」和「少熬两年夜班」不在一把尺子上，没法分高下                                                                                                          |
| 收益量级 | 大 / 中 / 小                | 尽量照着条目自己的「收益」栏，按事先定好的界线套，不凭感觉：换钱看金额（万元级为大，数百到数千为中，几十元为小）；换人身自由看后果（避免刑事责任为大，避免拘留或行政处罚为中，避免民事纠纷为小）；换时间精力看省下多少（每天省出小时级为大，每周小时级为中，只省一次的为小）；换健康看后果（避免致残或致命为大，避免慢性病为中，轻微改善为小） |
| 性价比  | 极高 / 高 / 一般              | 好处大、三项成本又全是零 = 极高；好处大、成本不高，或者好处中等、成本为零 = 高；剩下的 = 一般                                                                                                                     |

中间那档条数多是有意的：底下的收益量级本来就只分大、中、小三级，再往细里切就是装出来的精确。

**这一档是作者自己的判断，不是证据**，按本书的标准它本身只算 C 级；它和证据等级是两回事，谁也不影响谁。一条可以证据是 A 级、性价比却只算一般，也可以证据只有 C 级、性价比却极高。「一般」不等于不该做——全书的条目都是建议做的，只是这一档得你自己掂量那笔花销值不值。

## 正文

正文按节拆成 134 个文件放在 [book/](book/)，点上面目录里的节名进入。拆开是为了单文件不超过 GitHub 渲染 Markdown 的上限，也为了改一条时只动一个文件；[在线检索页](https://tomcatmartion.github.io/Workplace-Survival-Handbook/)会把这些文件合起来读，用法不变。

每节文件的第一行是回总目录的链接，第二行空行，第三行是 `# N. 节名`。节名之下是节首引言，写清这一节算什么、口径是什么、条目怎么排序。
