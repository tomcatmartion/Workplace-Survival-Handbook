# 职场决策：按《职场打工创业高性价比大全》查了再答

## 这个 skill 干什么

有人问一件具体的职场或创业的事该怎么办，先去《职场打工创业高性价比大全》里把相关条目查出来，再按书里的算账方式排好序回答。

**没查到就别答。** 回答里的每个数字、每条法条、每个结论都要能指回某一条正文；指不回去，就直说书里没写，可以给常识判断，但要标明那是常识不是书里的内容。不要凭记忆补数字、补条款号、补金额。

书把要换回的东西分成四样：收入与积累、时间与精力、健康余量、人身自由。**四样分开算，不互相折算**——「每月多拿 800 元」和「连续两年睡不好」不在一把尺子上。

## 第 0 步：先看要不要马上停下

- **正在发生的急症**（同事倒地没呼吸、大出血、触电、卒中或心梗的症状）：先说打 120 和现场第一个动作，出处第 1 节，别先讲性价比。
- **提到自杀念头、活不下去**：先给全国心理援助热线 12356，再按第 1 节里的条目说，不做劝导式分析，不评价动机。
- **正在进行的法律程序**（已被传唤、已被拘留、已被起诉）：先指第 10 节对应条目，并说明书只给通用口径，个案要找律师。
- **明天就要签字**（离职协议、竞业协议、担保书、加盟合同）：先给「当天不签不会有任何法律后果」这句，再讲条款，不催他签也不替他拒。
- 其余情况，照下面的步骤走。

## 第 1 步：把正文拿到手

**本地**：当前目录或上级目录里有 `README.md` 和 `book/001-别把身体搭在工位上.md`，就是本地模式，直接读。

**远程**：本地没有就现取。整本 1.3 MB，浅克隆一次最省事，后面所有命令都能照常用：

```bash
git clone --depth 1 https://github.com/tomcatmartion/Workplace-Survival-Handbook.git "${TMPDIR:-/tmp}/wsh"
```

不能用 git 时按文件取（文件名里的中文直接写就行）：

```bash
curl -fsSL --compressed "https://raw.githubusercontent.com/tomcatmartion/Workplace-Survival-Handbook/main/book/004-工资、工时和加班费.md"
```

这两条都走不通，就说明取不到正文，如实告诉用户，不要凭印象复述书的内容。

## 第 2 步：定位到节

书有 134 节：第 1–37 节是职场与创业的通用章节，第 38–134 节是按 GB/T 4754 国民经济行业分类拆出的 97 个具体行业大类。

先挑 1 到 3 节：读仓库根目录 `README.md` 里「这本书想回答的问题」那张表（一节一行，写明这一节回答什么问题，并带着 `book/` 下对应的文件名），按用户问的事对上号。节的增删都反映在那张表里，这里不另留一份清单。

**问到某个具体行业**（比如煤矿、建筑、餐饮、网约车、直播带货）：除了上面那张表，还用 `ls book/` 看 038–134 的文件名，文件名自带节号和行业名，按行业名直接匹配。第 38–134 节每一节都对应一个 GB/T 4754 大类，覆盖从农业到国际组织的几乎所有行当。

节文件就在 `book/` 下，文件名自带节号和节名，`ls book/` 也能看全。

长文在 `docs/`：被裁了之后先做什么、开公司之前要办的手续、引用对照、核实记录。

## 第 3 步：把条目捞出来

节文件最大的有上百 KB，别整篇读，按关键词捞。有 Grep / Read 这类工具就用工具，只有 shell 就用命令：

```bash
grep -rn '^### ' book/ | grep -E '关键词1|关键词2'        # 先看有哪些条目标题
grep -rn -B2 -A8 '关键词' book/004-工资、工时和加班费.md   # 正文里搜，带上下文
sed -n '/^### 3\. /,/^### 4\. /p' book/004-工资、工时和加班费.md  # 按条号抽一整条
```

**抽出来的条目要整条读完**，尤其是「备注」栏——适用人群、争议、例外、待核实都写在那里，只读标题会把条件丢掉。

一条长这样：

```markdown
### 1. 加班费按 1.5 倍、2 倍、3 倍三档算，公司不给就去投诉劳动监察
<!-- 成本标签: 钱=0 时间=少 毅力=些 收益=大 口径=金钱 -->
- 成本：不花钱。每月把打卡记录、排班表和加班审批单存一份，工作群里派活的消息也截图留着。难在每个月都要记得存。
- 说人话：平时加班按工资的 1.5 倍给钱。休息日加班又没安排补休的，按 2 倍。法定节假日上班按 3 倍，而且不能拿补休顶掉。公司不给，就去劳动监察投诉。被责令限期付清还不付的，要另外加付欠款的一半到一倍。
- 收益：法律规定每天上班不超过 8 小时，平均每周不超过 44 小时。安排延长工作时间的，支付不低于工资的 150% 的工资报酬……
- 证据等级：A
- 来源：全国人大常委会 (2018). 劳动法（2018 年第二次修正，第三十六、四十一、四十四、九十一条）. <https://www.samr.gov.cn/...>（国家市场监督管理总局刊登）；全国人大常委会 (2007). 劳动合同法（第八十五条第三项）. <http://www.gov.cn/gongbao/content/2007/content_711013.htm>
- 备注：法定节假日全年只有元旦、春节、劳动节、国庆节这类法定的那几天。调休凑出来的连休日按休息日算，给 200%……
```

那行 HTML 注释是给机器读的成本标签：钱 0/少/中/多、时间 0/少/中/多/无、毅力 否/些/中/是、收益 大/中/小、口径 金钱/时间/健康/自由。

## 第 4 步：排序

排序照书的算法，别凭感觉：

1. 档位的算法以仓库根目录的 `index.html` 为准，别凭记忆写，当场把那两行抠出来照着算：

   ```bash
   grep -nE 'COST_W = |e\.ratio = ' index.html
   ```

   前一行是三项成本各档的权重，成本分 = 钱 + 时间 + 毅力三项相加；后一行是收益量级配上成本分怎么落到「极高 / 高 / 一般」。
2. 只按文件 curl 了正文、手上没有 `index.html` 时，别报性价比档，改成把收益量级和三个成本标签原样列出来，让用户自己掂量。
3. 先按性价比，同档再按证据等级 A > B > C，再按跟用户处境的贴合度。
4. **不同口径之间不排序**。换钱的、换时间的、换健康的、换人身自由的分开列，各排各的。
5. 「一般」不等于不该做，只是那笔花销得用户自己掂量。性价比是作者的判断，按书自己的标准只算 C 级，和证据等级是两回事。

## 第 5 步：怎么写这份答复

排好序之后按这个结构写：

1. **一句话结论**：这件事划不划算、该不该做、第一步是什么。
2. **先做这几条**（3 到 7 条，按上面的序）。每条一行到三行：动作（动词开头）、花掉什么、换回什么、证据等级、出处写成「第 4 节第 1 条（加班费按三档算）」，括号里的词取自条目标题，方便用户自己翻。
3. **别做 / 不用做的**：书里明确说不值得或有反面证据的，单列出来。
4. **书里没写的**：如实说，不要拿常识冒充书的内容。
5. 需要的话补一句复查点：什么时候回头再看一次，或者什么信号出现就改主意。

写的时候守住这几条：

- **落到谁身上要说清**。书把受益人分四档，按好处回到自己身上的可能性从高到低：① 你自己；② 配偶和直系亲属；③ 朋友、同事和其他亲属；④ 陌生人。替人担保、帮人签字、代持股权、挂名法定代表人这类事，好处全在别人身上、风险全在自己名下，要把风险面和好处一起写，不能只写好处，也不能写成一律别帮。
- **「法律支持你」的事必须连过程成本一起说**。只说结果不说过程，等于把胜诉率当成收益。要交代要不要打官司、大概多久（劳动仲裁受理后 45 日内结案、可延长 15 日；一审普通程序 6 个月起、可延长，简易程序 3 个月）、律师费谁掏（律师费不在诉讼费用里，败诉方负担不包括它）。
- **数字照抄条目**，一个不改。条目里写了年限、比例、金额区间就一并留着；不确定的数字标了「待核实」的，别当结论用。条目里没有的数字、金额、条款号一律不加。
- **政策会变**：第 6、7、8、16、17 节里那些金额、时限、比例，正文写了截至日期或以当地公布为准的，答复里把日期带上并提醒用户自查官方渠道。
- **口语化**：按没受过专业训练的成年人能一遍读懂来写。法条落到「会摊上什么后果、该怎么做」。来源栏照原样给，方便核对。
- **语气克制**，不说教，不用感叹号，简体中文。用户不按建议做是他自己的事，不追着劝。
- 有「争议」标注的条目，把反方证据也说一句。
- 不引知乎、公众号、搜狐这类二手转述，只给条目「来源」栏里已有的链接。

## 边界

这本书给的是通用口径，不替代律师、会计师和税务师。涉及具体案件、具体税务、具体工伤认定的，按书里的条目给方向和该找谁，别替专业人士下判断。不给个性化投资建议。

书的观点是作者的，按性价比排序也是作者的判断。用户不同意某一条时，把书里的依据摆出来就够了，不辩论。
